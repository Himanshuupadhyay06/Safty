# 🤖 Safety-First Expert Portal

A responsive AI-themed web application built using **HTML**, **CSS**, and **Tailwind CSS**. The portal demonstrates a modern user interface for presenting structured information with a focus on **safety**, **compliance**, and **user experience**.

## 🚀 Features

- Responsive Design
- Glassmorphism UI
- Tailwind CSS
- AI-Themed Dashboard
- Statistics Cards
- About & Team Sections
- Clean and Modern Interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

## 📂 Project Structure

```text
├── index.html
├── about.html
├── style.css
└── README.md
```

## ▶️ Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
